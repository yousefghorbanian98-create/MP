# آماده‌سازی پیش از loop — ۲۰۲۶-۱۱-۱۸

این گزارش آماده‌سازی است، نه اجرای QF-00 یا توسعهٔ قابلیت محصول. نقش‌بندی برنامه برای آماده‌سازی پذیرفته شده و ECC انتخاب فعلی است؛ نصب فایل نقش به معنی اجرای زیراجنت یا review مستقل نیست.

## شواهد این نوبت

- Node 24.22.3 و `rea-agents` 6.9.0 با npm و بدون lifecycle script در یک پوشهٔ موقت و خارج مخزن نصب و نسخه‌ها تأیید شد. `inspect-api-contract` روی فایل OpenAPI **ساختگی** با دو endpoint آفلاین exit 0 داد؛ خروجی هر دو endpoint را داشت. این تست، ارزیابی کامل پروژه یا اتصال MCP به Arena نیست.
- `rea doctor --format json` در حالت پیش‌فرض audit-wide، exit 1 و `healthy=false` داشت. Node و host موفق، Hopper، Ghidra، IDA registration، JADX، Kuna و skill identity ناموفق بودند. این با موفقیت تست محدود OpenAPI تناقض ندارد؛ آماده‌بودن همهٔ providerها یا skill/MCP را ثابت نمی‌کند.
- کد منبع ECC پین‌شده در `.finn/ecc-commit.txt` به محیط موقت دریافت شد (بستهٔ `ecc-universal` نسخهٔ 2.2.3، مجوز MIT، ۷۱ فایل نقش). `consult` آفلاین برای مسئلهٔ ساختگی exit 0 و شش پیشنهاد داد؛ مشاورهٔ heuristic است، نه اجرای مدل، parent/child یا QA مستقل. فایل نقش‌های ضروری منتخب موجود بودند. از این مشاهده محدود نباید دربارهٔ سایر نشست‌های Arena نتیجه‌گیری کرد.
- علت شکست قبلی نصب REA بررسی شد: تنها تفاوت پوشهٔ skill موجود، فایل افزودهٔ `LICENSE-REA` است که دقیقاً با مجوز بسته یکسان است. مقایسهٔ مستقل غیرمخرب `finn/check-rea-skill.sh` اضافه و به نصب‌کننده متصل شد؛ اجازه فقط برای همان فایل ریشه با تطبیق byte-for-byte است. سایر تفاوت‌ها و symlink رد می‌شوند. `finn/test-check-rea-skill.sh` شش حالت مثبت/منفی را گذراند؛ نصب‌کنندهٔ REA نیز در کپی کاملاً ساختگی با تنظیم MCP ساختگی exit 0 داد و سرور دیگر را حفظ کرد. نصب واقعی پروژه یا reload/connect میزبان در این نوبت انجام نشد. نصب‌کننده در صورت وجود، ورودی `rea` در `.mcp.json` را جایگزین می‌کند؛ قبل از اجرای واقعی باید آن پیکربندی و مقصدهای موجود جداگانه بررسی شوند.
- `python3 scripts/docs_gate.py` موفق: ۱۲ Markdown، ۱۸۵ لینک محلی و ۹ بلوک Mermaid؛ `git diff --check` و بررسی syntax اسکریپت‌ها موفق. اینها QA محصول یا CI نیستند.

- HEAD محلی `5482930587ce18e14f136d78296542a2de5af091` نیای شاخهٔ remote با SHA `8e72de9b5e450b38cb3871f7d5f4383595dbdd1b` است. از ۲۶ فایل تغییرکردهٔ آن بازه، محتوای ۲۴ فایل در worktree فعلی برابر remote بود؛ `.finn/state/LEDGER.md` و `.finn/state/STATE.md` تفاوت محلی دارند. dry-run fast-forward قبلی به علت همین فایل‌ها شکست خورد. تطبیق محتوا به‌تنهایی اجازهٔ overwrite یا انتشار سایر تغییرات را نمی‌دهد؛ staged خالی بود. هیچ pull، reset، merge، commit یا push انجام نشد.
