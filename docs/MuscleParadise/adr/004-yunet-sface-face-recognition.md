# ADR-004 — YuNet/SFace به‌جای InsightFace برای تشخیص چهره

> وضعیت: **پذیرفته** | تاریخ: 2026-11-14 | چرخه: M02 | تصمیم‌گیرنده: architect (FINN)

## زمینه
گیت ورود باشگاه باید چهره را در < ۲ ثانیه شناسایی کند؛ دادهٔ بیومتریک باید رمزنگاری و حداقلی باشد. کد محصول باید لایسنس تجاری‌سازگار داشته باشد.

## گزینه‌ها
1. **OpenCV YuNet (تشخیص چهره) + SFace (embedding)** — هر دو Apache-2.0/BSD، سبک، مناسب Raspberry Pi
2. InsightFace — کیفیت بالاتر، ولی لایسنس غیرتجاری (non-commercial) برای مدل‌ها
3. سرویس ابری تشخیص چهره — مغایر با local-first و حریم خصوصی دادهٔ ایرانی

## تصمیم
**گزینهٔ ۱** — YuNet برای تشخیص/کادربندی + SFace برای embedding + لایهٔ liveness ساده (حرکت/عمق/چالش) + fallback QR.

## دلایل
- لایسنس آزاد (Apache-2.0) برای محصول تجاری
- کارایی مناسب روی سخت‌افزار Pi (مدل‌های کوچک ONNX)
- طرح ۱۶ لایه (پیوست الف) این انتخاب را تأیید کرده است

## پیامدها
- ✅ بدون ریسک لایسنس؛ اجرای محلی؛ داده از سرور خارج نمی‌شود
- ⚠️ دقت پایین‌تر از مدل‌های بزرگ در نور ضعیف → liveness سخت‌گیرانه + fallback QR/پذیرش (US-106)
- ⚠️ فقط embedding رمزنگاری‌شده (PyNaCl) ذخیره می‌شود؛ تصویر خام نگهداری نمی‌شود (NFR-3)
