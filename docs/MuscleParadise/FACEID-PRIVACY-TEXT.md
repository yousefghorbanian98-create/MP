# متن حریم خصوصی تشخیص چهره (M31) — `faceid-privacy-1.0`

> منبع حقیقت همین سند است؛ نسخهٔ ماشین‌خوان همان متن در `modules/face_id/privacy.py`
> و از `GET /api/v1/face/privacy-notice` در دسترس کلاینت است (نسخه‌دار).

## اصل‌ها
1. **حداقل‌سازی داده**: فقط بردار چهرهٔ رمزنگاری‌شده؛ بدون عکس/ویدیوی خام.
2. **رضایت آگاهانه و اختیاری**: ورود جایگزین (پیامک) بدون هیچ محرومیتی.
3. **حق حذف فوری**: `DELETE /face/enroll/{member_id}` — حذف قطعی، بدون بایگانی مخفی.
4. **بدون ثالث و بدون ردیابی**: کاربرد انحصاراً ورود/چک‌این.
5. **مدت نگهداری**: تا لغو رضایت یا پایان عضویت + ۳۰ روز (E10).
6. **شفافیت الگوریتم**: درجهٔ اطمینان/آستانه در پاسخ API اعلام می‌شود؛ مدل‌های عمیق پشت `model_lock`
   (D-008) — تا تأمین منبع مستقل/اجازه، از مدل تأییدشدهٔ HOG استفاده می‌شود (شواهد: `finn/reports/faceid-evidence/`).

## متن رضایت‌نامه (نمایش به کاربر پیش از ثبت چهره)
«با ثبت چهره، به MuscleParadise اجازه می‌دهم قالب ریاضی چهرهٔ مرا (نه عکس) به‌صورت رمزنگاری‌شده
ذخیره و فقط برای ورود/چک‌این استفاده کند. می‌دانم که: ثبت اختیاری است؛ جایگزین پیامکی دارم؛
هر وقت بخواهم می‌توانم رضایتم را لغو کنم و دادهٔ من فوراً و قطعاً حذف می‌شود؛ داده‌ام به ثالث
منتقل یا برای تبلیغات استفاده نمی‌شود.»
