# چک‌لیست بازبینی رابط وب (مرحلهٔ S4 هر میکرو-لوپ)

> منبع: `vercel-labs/web-interface-guidelines` (MIT) — در تاریخ ۲۰۲۶-۱۱-۱۴ دریافت شد.
> نحوهٔ استفاده: ECC-5 (جهان‌اول) در هر میکرو-لوپی که UI استودیو/وب را لمس می‌کند، این قواعد را اجرا و یافته‌ها را با قالب `file:line` گزارش می‌کند.
> برای کلاینت فلاتر: معادل‌های Material/RTL در `DESIGN.md` (§۶) بازبینی می‌شود.

## دسترس‌پذیری (A11y)
- دکمه‌های فقط-آیکون → `aria-label`
- کنترل‌های فرم → `<label>` یا `aria-label`
- عناصر تعاملی → handler کیبورد (`onKeyDown`/`onKeyUp`)
- اکشن → `<button>`؛ ناوبری → `<a>/<Link>` (هرگز `<div onClick>`)
- تصاویر → `alt` (دکوراتیو: `alt=""`)
- آیکون دکوراتیو → `aria-hidden="true"`
- به‌روزرسانی async (toast/اعتبارسنجی) → `aria-live="polite"`
- اول HTML معنادار، بعد ARIA
- سرتیترها سلسله‌مراتبی `<h1>`–`<h6>` + skip link
- `scroll-margin-top` روی anchor سرتیترها
- مدیای معنادار → زیرنویس/رونوشت؛ کنترل مدیا → پشتیبانی کیبورد

## حالت فوکوس
- حلقهٔ فوکوس مرئی (`focus-visible:ring-*`)؛ هرگز `outline-none` بدون جایگزین
- `:focus-visible` به‌جای `:focus`؛ `:focus-within` برای کنترل‌های ترکیبی
- هدر/پاورقی چسبان نباید عنصر فوکوس‌شده را بپوشاند

## فرم‌ها
- `autocomplete` + `name` معنادار؛ `type`/`inputmode` درست
- هرگز جلوی paste را نگیرید
- لیبل قابل‌کلیک؛ چک‌باکس/رادیو: یک هدف لمسی مشترک
- دکمهٔ ثبت تا شروع درخواست فعال بماند؛ حین درخواست spinner
- خطاها inline کنار فیلد؛ فوکوس روی اولین خطا هنگام submit
- placeholder با `…` + الگوی نمونه
- هشدار قبل از خروج با تغییرات ذخیره‌نشده

## انیمیشن
- `prefers-reduced-motion` رعایت شود (نسخهٔ کاهش‌یافته یا غیرفعال)
- فقط `transform`/`opacity` انیمیت شوند (کامپوزیتور-فرندلی)
- هرگز `transition: all` — خواص را صریح بنویسید
- `transform-origin` درست؛ SVG: روی `<g>` با `transform-box: fill-box`
- انیمیشن‌ها قابل‌وقفه باشند (پاسخ به ورودی کاربر)
- حلقه‌های دکوراتیو بی‌صدا زیر `prefers-reduced-motion` متوقف شوند

## تایپوگرافی
- `…` نه `...`؛ گیومهٔ منحنی نه صاف
- فاصلهٔ بدون‌شکست: `10&nbsp;MB`، نام‌های برند
- حالت بارگذاری با `…`: «در حال ذخیره…»
- `font-variant-numeric: tabular-nums` برای ستون‌های عددی
- `text-wrap: balance` روی سرتیترها

## محتوا
- متن بلند: `truncate`/`line-clamp`/`break-words`؛ فلکس‌فرزند → `min-w-0`
- حالت خالی طراحی شود (هرگز UI شکسته برای ورودی خالی)
- ورودی کاربر: کوتاه/متوسط/خیلی‌بلند پیش‌بینی شود

## تصاویر
- `<img>` عرض/ارتفاع صریح (جلوگیری از CLS)
- زیرخط تاشو → `loading="lazy"`؛ بالای خط → `priority`

## کارایی
- لیست >۵۰ مورد → virtualize
- بدون خواندن layout در render؛ batch خواندن/نوشتن DOM
- ورودی‌های uncontrolled ترجیح داده شوند
- `preconnect` برای دامنه‌های CDN؛ فونت بحرانی → preload + `font-display: swap`
- ویدئوی `autoplay muted loop playsinline` به‌جای GIF متحرک

## ناوبری و وضعیت
- URL بازتاب وضعیت (فیلتر/تب/صفحه‌بندی)
- لینک‌ها `<a>/<Link>` (پشتیبانی Cmd/Ctrl+click)
- اکشن مخرب → مودال تأیید یا پنجرهٔ undo — هرگز فوری

## لمس و تعامل
- `touch-action: manipulation`؛ `-webkit-tap-highlight-color` آگاهانه
- `overscroll-behavior: contain` در مودال/کشو
- حین درگ: غیرفعال‌سازی انتخاب متن
- ژست‌ها → جایگزین tap/click/کیبورد مگر ضروری
- `autoFocus` فقط دسکتاپ، یک ورودی اصلی

## ناحیهٔ امن و چیدمان
- چیدمان تمام‌عرض → `env(safe-area-inset-*)`
- جلوگیری از اسکرول‌بار ناخواسته؛ فلکس/گرید به‌جای اندازه‌گیری JS

## تم تاریک
- `color-scheme: dark` روی `<html>`؛ `<meta name="theme-color">` هم‌رنگ پس‌زمینه
- `<select>` بومی: رنگ پس‌زمینه/متن صریح

## i18n
- تاریخ/عدد/ارز با `Intl.*` نه قالب سخت‌شده
- زبان از `Accept-Language`/`navigator.languages`
- نام برند/توکن‌ها: `translate="no"`

## ضدالگوها (پرچم بخورد)
`user-scalable=no` | جلوگیری از paste | `transition: all` | `outline:none` بدون جایگزین | ناوبری با `onClick` inline | `<div>` با click handler | تصویر بدون ابعاد | لیست بزرگ بدون virtualize | ورودی بدون لیبل | دکمهٔ آیکونی بدون `aria-label` | قالب تاریخ/عدد سخت‌شده | GIF متحرک به‌جای ویدئو | ژست بدون جایگزین

## خروجی بازبینی
گروه‌بندی بر اساس فایل، قالب `file:line` (کلیک‌پذیر)، موجز. فقط مسئله + مکان؛ توضیح فقط اگر رفع غیربدیهی است.
