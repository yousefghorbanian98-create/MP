## ۳. مسیر یک میکرو‌لوپ: هر ایستگاه را چه چیزی حمل می‌کند

میکرو‌لوپ چهار ایستگاه دارد (بند «چرخهٔ اجباری» پلن). این جدول می‌گوید در هر ایستگاه
چه ابزاری واقعاً اجرا می‌شود — نه آنچه آرزو داریم.

| ایستگاه | حامل | خروجی اجباری |
|---|---|---|
| **Forge** (طراحی برش) | `git` + `gh` + `rg` (grep) + `python3`؛ خواندن PLAN/TODO/OWNER-DECISIONS؛ **هیچ ایجنت بیرونی اجرا نمی‌شود** | برش n با فایل‌های دقیق و دامنهٔ اثبات |
| **Inspect** (بازرسی) | `mp-app/backend/api/routes.json` + `scripts/export_routes.py` + `scripts/route_guard_gate.py`؛ تست `apiCoverage`؛ مهارت REA به‌صورت **مرور دستی**؛ grep خط‌به‌خط | فهرست گپ: هر action بدون API/تست/مدل |
| **Normalize** (سخت‌سازی) | `pytest` + coverage + `ruff`؛ `vitest` + `tsc` + `vite build`؛ `flutter analyze` + `flutter test`؛ `scripts/docs_gate.py`؛ `gitleaks`؛ `npm audit`؛ `pip-audit`/`bandit` | همهٔ گیت‌های Q0–Q11 سبز + شاهد عددی |
| **Next** (checkpoint) | `gh run watch` روی همان SHA؛ commit انتخابی؛ `git push` به شاخهٔ جاری؛ ثبت در ledger و SESSION_HANDOFF | CI ۸/۸ + SHA + فهرست «تصمیم‌های کم‌اطمینان» |

نکتهٔ صادقانه: **زیر‌ایجنت اجرا نمی‌شود.** اجرای زیر‌ایجنت ECC در این میزبان شکست خورده و
حذف شده است. هر جا در گزارش‌ها «بازبینی» می‌بینید یعنی مرور دستی من، و همین‌طور برچسب
می‌خورد؛ ادعای بازبین مستقل نداریم.

## ۵. فازها به ترتیب

هر فاز یک یا چند میکرو‌لوپ است؛ هر لوپ همان چرخهٔ چهارایستگاهی بالا را طی می‌کند و
بدون CI سبز روی همان SHA بسته نمی‌شود.

### فاز ۰ — بستن باقی‌ماندهٔ Q11 ✅ انجام شد (۲۰۲۶-۱۱-۱۹)
- [x] چهارده `<input>` خام در `mp-app/studio/src/pages/Shop.tsx` → `Input` و `InputNumber` با `stringMode`.
- [x] گیت Q11 دو الگوی تازه گرفت: ورودی خام و textarea خام؛ تست اول قرمز شد.
- [x] بدهی دوازده فایل دیگر در `tests/uiControlBudget.json` ثبت شد؛ فایل تازه سهمیه ندارد.
- [x] `required` مرورگر با گارد فارسی در handler جایگزین شد؛ پیام خطا در توست نمایش داده می‌شود.
- شاهد: `vitest` ۲۳۴ قبول / ۹ رد‌شده، `tsc -b` پاک، `vite build` بدون هشدار، صفر ورودی خام در Shop.

نکتهٔ اجرایی: `InputNumber` بدون `required` است؛ پس اعتبارسنجی خالی‌بودن به handler منتقل شد
و آن گارد در همان فایل تست می‌شود، نه در CSS یا قواعد نامرئی.

### فاز ۱ — بستن گیت QF-00: نقشهٔ سطح تعامل (۱–۲ لوپ)
- برای هر صفحهٔ استودیو (۱۲ صفحه) و هر مسیر کلاینت: فهرست دکمه/فرم/منو با role، فراخوانی API از `api/routes.json`، جدول DB، تست موجود.

- بازبینی نقش‌های coach / reception / admin در همان قالب.
- پذیرش: سند نقشه + فهرست گپ + QA دستی برچسب‌خورده + checkpoint سبز.

### فاز ۲ — فروشگاه نمایش‌محور و ساعات کاری (۲ لوپ)

- استودیو: مدیریت محصول و قیمت دست‌نخورده می‌ماند (کار مالک)، فقط نمایش وضعیت.
- گیت بند ۲.۲ لازم نیست (پول جابه‌جا نمی‌شود) اما Q9 (RTL/فارسی/دسترس‌پذیری) کامل.
