## ۲. یافته‌های مهم پیش از هر تصمیم محصول

1. **این بسته proposal و recipe مرجع است، نه source محصول MP.** خود README، START_HERE، manifest و گزارش verification چند بار «KIT ONLY / NOT PRODUCT QA» را تصریح می‌کنند.
2. `references/MP_SOURCE.json` به snapshot استاتیک MP در commit `0e69b56dd0c427e45f2c104613cc420ea1a8c49f` اشاره دارد، نه HEAD/worktree امروز. مقایسهٔ قبلی با HEAD همین شاخه نشان داد از ۱۱ مسیر پین‌شده، ۸ مسیر مطابق و سه فایل Studio محلی متفاوت‌اند: `mp-app/studio/src/main.tsx`، `mp-app/studio/tailwind.config.js` و `mp-app/studio/src/styles/index.css`. محتوای کامل این سه diff در این بازبینی تعیین تکلیف نشده؛ recipe نباید کورکورانه روی آن‌ها اعمال شود.
3. **ناسازگاری تاریخ محتوا:** تاریخ فعلی این نشست ۲۰۲۶-۱۱-۲۳ است، اما package شامل `SOURCE_PLAN.fa.md` با تاریخ ادعایی ۲۰۲۶-۱۱-۲۴ (L3)، گزارش review مورخ ۲۰۲۶-۱۱-۲۴، و clockهای ۲۰۲۶-۱۱-۲۵ در `BROWSER_CHECK.json` و `OPEN_SOURCE_TOOLS.json` است. این‌ها تاریخ‌های آینده نسبت به زمان بازبینی‌اند؛ به‌خودی‌خود اثبات جعل یا خرابی نیستند، اما منشأ/زمان باید از صادرکننده روشن شود و تا آن زمان گزارش review/اجرای آینده، شاهد تاریخیِ قبلاً واقع‌شده یا approval تلقی نشود. فایل‌ها دست‌کاری نشدند.
4. `PWA-00-REVIEW-2026-11-24...` نتیجهٔ خوداظهاری `CHANGES_REQUESTED — DOCUMENTS_ONLY` و R-01 تا R-03 را نگه می‌دارد. به‌علت ناسازگاری تاریخ و ماهیت مندرج در همان فایل، این محتوا مرجع ردیابی/تاریخی است، نه وضعیت جاری branch، مجوز retry یا approval محصول.
5. `PLAN_IDENTITY.json` و validator، ۵۰ parent اصلی را حفظ می‌کنند (`[6,8,5,16,8,7]`)؛ `PWA-56` آخرین شناسه است، نه تعداد. عنوان/AC/شناسه‌های parent نباید با loopهای محلی این سند بازشماره‌گذاری، ادغام یا جایگزین شوند.
6. سه گروه باید از هم جدا بمانند: recipeهای **TypeScript/React برای Studio/PWA**؛ فایل‌های HTML/CSS/JS پیش‌نمایش **وبِ کیت و فقط شاهد طراحی**؛ و ورودی‌های طراحی/platform-neutral که می‌توانند بعداً برای Android بررسی شوند. فایل‌های Python، lock، log، manifest و harness نیز ابزار/سند evidence هستند و به خودی خود نه قابلیت PWA و نه کار Android محسوب می‌شوند.
7. هیچ دادهٔ عضو/رسید/سلامت، authorization سمت سرور، پرداخت/بانک، نصب PWA/offline/update واقعی، تست روی Android یا آمادگی انتشار با این ZIP اثبات نمی‌شود. «سلامت داخلی فایل» فقط تمامیت بایت‌های package است؛ امضای ناشر یا گواه «کلاس جهانی» نیست.
