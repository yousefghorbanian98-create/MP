## A. ادعاهای ثبت‌شده در زمان تدوین این فرم

Checkboxهای این بخش در snapshot اولیهٔ review باز مانده‌اند؛ اکنون سابقهٔ بازبینی‌نشده‌اند، نه TODO جاری یا گزینهٔ فعال. آن‌ها را به‌جای وضعیت فعلی از دفتر پاسخ مالک و TODO PWA نخوانید.

- [ ] نقش‌های جاری در نمودار: `member`, `coach`, `reception`, `manager`, `admin`, `super_admin`.
- [ ] **ادعای تاریخی این فرم، اکنون superseded:** کلاینت انتشار اول Flutter/Android برای عضو + Studio وب برای کارکنان بود؛ طبق OQ-01/ADR-007 baseline جاری PWA مشترک عضو/کادر است و Flutter/Android حفظ می‌شود.
- [ ] محل محصولیِ انتشار اول: سرور محلی باشگاه + ورودی HTTPS؛ exact host/domain/tunnel/backup/deploy هنوز اثبات نشده.
- [ ] فروشگاه عضو: catalog/display-only، online checkout پیش‌فرض خاموش و API fail-closed.
- [ ] پرداخت انتشار اول: کارت‌به‌کارت + فیش خصوصی + بازبینی انسانی/تطبیق بانکی مستقل؛ درگاه live فعال فرض نشده.
