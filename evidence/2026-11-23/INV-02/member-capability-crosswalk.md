## تصمیم‌ها و معنای وضعیت

- [ADR-007](../../../docs/MuscleParadise/adr/007-pwa-primary-release.md) baseline انتشار اول را یک PWA مشترک React روی `mp-app/studio/` برای عضو و کادر تعیین می‌کند؛ Flutter/Android حفظ می‌شود. این ADR خودِ parity، route tree یا آماده‌بودن انتشار را تأیید نمی‌کند.
- حدهای صریح همان ADR: فروشگاه عضو **نمایش‌محور**؛ check-in با **QR و بدون تشخیص چهره**؛ پرداخت کارت‌به‌کارت با تطبیق انسانی؛ ادعای پزشکی ممنوع. این سند آن حدود را عوض نمی‌کند.
- `CURRENT` یعنی رفتار عضو در React از source قابل‌ردیابی است؛ صرف وجود یک page/API یا test file کافی نیست. `GAP` یعنی رفتار عضو در route جاری React موجود/معادل نیست. `TARGET` یعنی جهت یا سیاست هدف صریحاً پذیرفته شده، اما هنوز پیاده نشده (path زیرصفحه اگر در source/ADR تعیین نشده `TBD` است). `BLOCKED` یعنی به‌دلیل تضاد نقش، safety/privacy یا نیاز به تصمیم/قرارداد صریح، نباید قابلیت را به PWA منتقل/فعال کرد.
- هیچ ردیفی `CURRENT` نیست: در `App.tsx:100–102,169–180` مسیر `/member` فقط placeholder است و دادهٔ عضو بار نمی‌کند. `navigation.ts:17–19` نقش `member` را از `isStaffRole` خارج می‌کند و `App.tsx:105–107` پیش از نمایش هر `/staff/*` همین guard را اعمال می‌کند؛ بنابراین صفحه‌های شبیه در Studio—even اگر `PAGE_RULES` نقش member را فهرست کند—معادل قابل‌دسترسی عضو نیستند. route هدف برای هر زیرقابلیت از روی نام‌گذاری حدس زده نشده است.
