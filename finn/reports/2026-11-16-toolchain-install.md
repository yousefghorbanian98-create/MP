### محدودیت شفاف REA

`rea doctor` نتیجهٔ کلی `healthy: false` می‌دهد؛ این به معنی شکست نصب CLI نیست:

- Node و میزبان سالم گزارش شدند.
- Hopper، Ghidra، ثبت IDA، JADX و Kuna موجود/پیکربندی‌شده نیستند؛ این‌ها موتورهای اختیاری برای تحلیل‌های خاص‌اند و نصب نشدند.
- خود REA skill در پوشهٔ پروژه هست، اما چون setup هیچ IDE/client نصب‌شده‌ای شناسایی نکرد (`rea setup --dry-run`، بدون اقدام برنامه‌ریزی‌شده)، doctor آن را setup-managed نمی‌شناسد و `skill identity` را missing نشان می‌دهد.
- پس `.mcp.json` ثبت پروژه‌ای حاضر است، ولی فعال‌شدن آن در یک IDE مصرف‌کننده به بازکردن/بارگذاری مجدد همان client و تأیید MCP نیاز دارد. این runner هیچ clientای برای فعال‌سازی پیدا نکرد.

## ایجنت ECC انتخاب‌شده

برای بازبینی امنیت و ایمنی نصب از **`security-reviewer`** استفاده شد. فایل محلی آن با prompt همان ایجنت در ECC پین‌شده SHA-256 یکسان دارد. این یعنی prompt را به‌عنوان چک‌لیست به‌کار بردم؛ زیرعامل مستقل اجرا نشده است. برای بازبینی تغییرهای نصب‌کننده نیز چک‌لیست `code-reviewer` اعمال شد.

نتیجهٔ امنیتی مهم: دو نصب‌کنندهٔ قبلی می‌توانستند اجزای موجود `.claude/` را با `rm -rf` پاک و جایگزین کنند، و یکی از آن‌ها از فورک/شاخهٔ دیگری استفاده می‌کرد. این مسیر اجرا نشد؛ نصب‌کننده‌ها اصلاح شدند تا ECC را از commit پین‌شده بگیرند، فایل‌های موجود را حفظ کنند و فقط فایل‌های غایب را اضافه کنند. REA نیز روی نسخهٔ `6.9.0` پین شد و پیکربندی MCP موجود با سرورهای دیگر merge می‌شود، نه اینکه کامل بازنویسی شود.

## وابستگی REA

`npm audit --audit-level=high`، ۳ مورد با شدت **moderate** از زنجیرهٔ `rea-agents → frida → minimatch` گزارش کرد؛ مورد high/critical گزارش نشد. `npm audit fix --force` اجرا نشد، چون پیشنهاد npm نسخهٔ REA را به `6.4.0` downgrade می‌کند و breaking است. این یافته‌ها را پنهان یا با downgrade ناخواسته حل‌شده اعلام نکردم.

## آزمون نصب‌کننده

- `bash -n` برای هر دو اسکریپت موفق بود.
- اجرای `install-toolchain.sh all` دو بار موفق شد؛ اجرای دوم هیچ فایل ECC تازه‌ای اضافه نکرد و اختلاف/overwrite گزارش نشد.
- `install-ecc.sh` اکنون فقط به نصب‌کنندهٔ پین‌شده و غیرمخرب delegate می‌کند.
- نصب و Node خارج از repository و gitignored هستند؛ برای بازسازی در این محیط:

```bash
bash docs/MuscleParadise/finn/install-toolchain.sh all
```
