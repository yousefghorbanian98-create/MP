## آنچه تحویل داده شد
`eval/llm_column.py` — اداپتور کامل و آماده:
- `availability()` — بررسی واقعی `GET /api/tags` (بدون فرض)
- `build_prompt()` — پرامپت ساختاریافته که JSON اکید می‌خواهد
- `query_llm()` — `POST /api/generate` با `format: json`
- `compare()` — تطبیق با ستون قواعد: حرکات ممنوع، توافق «هر دو ایمن»،
  «فقط LLM خطا کرد»، «فقط قواعد خطا کرد»

تنظیم با `OLLAMA_BASE_URL` و `MP_LLM_MODEL`. وقتی Ollama بالا بیاید،
همین کد بدون تغییر عدد تولید می‌کند.

## برای تکمیل در زمان دفاع
```bash
docker compose up -d ollama
docker exec -it ollama ollama pull llama3.1
cd mp-app/backend && PYTHONPATH=. .venv/bin/python -m eval.run_eval --llm
```
سپس جدول مقایسه از همین `compare()` تولید می‌شود.
